PC Checker Extreme

Installation Guide  ·  v1.0.0  ·  Gilliom Frontline Digital

1 What's in this folder

Your download contains two items:

app\ ← the bundled application (do not move)
Install PC Checker Extreme.exe

Keep them together. The installer reads from app\ — if you move the exe without the folder, it will not work.

2 Install

Double-click Install PC Checker Extreme.exe.

No administrator password is needed. The app installs to your personal AppData folder, not to Program Files.

When asked "Launch PC Checker Extreme now?" click Yes — your browser will open automatically.

3 First sign-in

On first launch, the app opens to a login page. Because it's a fresh install, no account exists yet. Create yours at:

http://127.0.0.1:8000/accounts/signup/

After signing up you are logged in immediately and ready to run your first scan.

4 Launching after install

Use the PC Checker Extreme shortcut in your Start Menu or on your Desktop. The browser opens automatically after a few seconds. There is no visible window — the server runs silently in the background.

Tip: Run the app as Administrator for the most complete hardware and Windows Update data (right-click the shortcut → Run as administrator).

5 Stopping the server

Use Start Menu → Stop PC Checker Extreme when you're done, or simply restart your PC. Closing the browser tab does not stop the server.

6 Uninstall

Open Settings → Apps, search for PC Checker Extreme, and click Uninstall. This removes the app, shortcuts, and registry entry. Your scan history is removed as well.

7 Troubleshooting

Browser shows "This site can't be reached" — the server takes 2–3 seconds to start. Wait a moment and refresh, or navigate to http://127.0.0.1:8000/ manually.

Port 8000 already in use — another app is using that port. Stop it, then relaunch PC Checker Extreme.

Antivirus quarantines the exe — this is a false positive common with PyInstaller-packaged apps. Add an exception for the install folder (%LOCALAPPDATA%\PC Checker Extreme) in your antivirus settings.
